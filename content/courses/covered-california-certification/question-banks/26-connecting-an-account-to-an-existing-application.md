    prompt: "List the steps for connecting a new online account to an application that is already on file."
    sampleAnswer: "The representative generates an access code for the consumer. On the sign-in page the consumer selects the option to create an account, which appears on the page in blue text. The next option is to link an existing application, and when the site asks whether there is an access code the consumer selects Yes and enters the code the representative has read out. The account details are then filled in so that they match the application, the terms are accepted, and the consumer goes to the next step and creates the account. The portal then returns the consumer to the sign-in screen and reports that the account was created successfully, and from there the consumer can register an email address or a phone number, or both, for one-time passcodes."
    explanation: "Look for the order, and for the two things that have to happen exactly as described: the Yes answer at the access-code question, and the details matching the application. An answer that stops at creating the account has missed the linking step, and an answer that puts the access code in after the account exists has the sequence reversed. Lesson section: Stage 2: Linking the new account to the application."
