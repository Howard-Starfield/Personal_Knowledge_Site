    prompt: "What does an access code do, where does a consumer get one, and what should you not do with the examples of codes that were read out in the training?"
    sampleAnswer: "The access code is what ties a new account to the application that already exists; without it the consumer ends up with an empty account and still cannot reach their records. The official site says a mailed notice carries the code and goes out once the application has been submitted, and that a consumer without one should call the Service Center on (800) 300-1506, where a representative can generate a new one. You should not memorise a table of letter-and-name pairs from the training: the recording gives one letter two different names inside the same code, and attaches another letter to a name that does not begin with it, so the code in the recording has five characters but no fixed length or shape is established. Read the code exactly as the consumer gives it."
    explanation: "Look for the three parts: what the code is for, the mailed notice and the Service Center route, and the warning about the letter-and-name pairs. An answer that states a confident five-character format fails on the last point, and an answer that leaves out the Service Center route leaves the consumer who has lost their notice with no way forward. Lesson section: Stage 3: The access code."
