> [!abstract] Local showcase
> This is a working preview of a public learning site: read an idea, follow its
> evidence trail, test your recall, and leave a visible question for the next
> pass. It contains original demonstration material—not imported course text.

## Learn in a loop, not a feed

The Fieldbook is organized around four operations. The amber rail is a route,
not a progress lock: every published page remains directly reachable.

## What this build proves

| Surface                                     | Status               | Try it                                                                                       |
| ------------------------------------------- | -------------------- | -------------------------------------------------------------------------------------------- |
| Public knowledge                            | Live                 | Open [Retrieval as a decision system](knowledge-systems/retrieval-as-a-decision-system).     |
| Guided course                               | Live content preview | Start [Frame the question](courses/retrieval-field-guide/lessons/01-frame-the-question).     |
| Search, explorer, tags, backlinks, popovers | Live Quartz features | Use the left tools and hover an internal link.                                               |
| Learning annotations and log                | Live                 | Read the callouts and [evaluation reminder](learning-log/evaluate-the-retriever-separately). |
| Answer disclosure                           | Preview              | Use the semantic recall card in [Feature field test](showcase).                              |
| Bank-backed scoring and session attempts    | Gated                | Awaiting the owner-approved executable quiz contract.                                        |
| Owner capture, comments, graph, media, sync | Later phases         | Shown as roadmap, not working controls.                                                      |

> [!note] Public by design
> Published notes, questions, answers, and explanations are visible without a
> login. Private source packages and pending captures never enter this build.
